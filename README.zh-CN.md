# UltraTears Windows

**Windows 优先，兼顾 NVIDIA 与 AMD。** 名称暂定，后续可调整。

本项目基于 [kuraeow/ultratears](https://github.com/kuraeow/ultratears) 独立维护，
保留上游 Git 历史、作者信息和原有 GPL 许可证，并非从零编写的移植，也不是上游官方发行版。
原项目的重编译器、运行时、Vulkan 实现和构建流程应归功于原作者及贡献者。

## 开发方向

- 优先 Windows 上的画面正确性、稳定性和可复现的性能改进。
- 同时考虑 NVIDIA、AMD，分别记录显卡型号、驱动与测试结果。
- 改善键鼠和手柄操作，选择性吸收经过审查、测试的社区 PR。
- 暂不投入 Linux、Steam Deck 或新的跨平台启动器开发。
- 不以峰值帧率代替稳定性结论，不把单台机器的结果推广为全平台保证。

## 当前状态

| 项目 | 已知情况 |
|---|---|
| AMD | RX 6750 GRE 12 GB 上，用户已确认附件复制回退解决了所测场景的黑屏；不代表全流程验证 |
| NVIDIA | 有一台笔记本可用于测试；具体 GPU、驱动和本修改版的结果尚待记录 |
| 性能 | 当前测试尚不能在 1080p 稳定 30 帧；四线程录制仍为实验设置 |
| 键鼠 | 已实现调试映射与鼠标模拟右摇杆，并非直接控制相机的原生鼠标方案 |
| 发布 | 尚未发布本维护版；英文旧说明中的上游下载链接不包含我们的改动 |

现有调试映射：E → A、Q → B、空格 → X、鼠标左键 → Y、右键 → ZL、
Esc → −、Tab → +，鼠标移动 → 右摇杆。F1 捕获/释放鼠标；切出窗口自动释放并清空按键。

## 构建与数据

当前副本只包含源码及已跟踪的文档，不复制原工作目录里的游戏、字体、存档、缓存或构建产物。
在本仓库目录中，可指定自己已有的 1.4.3 解包目录：

```powershell
python tools/setup.py --dump D:\Dumps\TOTK-1.4.3
```

解包目录应包含 `exefs` 和 `romfs`。程序及数据在本机生成，不能随源码发布。
此复制操作没有重新编译或启动游戏，也没有创建、推送 GitHub 仓库。
